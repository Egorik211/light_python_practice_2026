Этап 2: Реализовано рекурсивное сканирование папки через os.walk. Для каждого файла собираются метаданные: полный путь, размер в байтах и дата последнего изменения. Размер форматируется в читаемый вид (Б/КБ/МБ/ГБ). Список файлов выводится в консоль построчно, в конце — итоговое количество файлов.

Функция scan_directory получает список содержимого папки через os.listdir, затем для каждого элемента проверяет: если файл — собирает метаданные (путь, размер, дата изменения), если папка — вызывает себя рекурсивно. 
13.06.2026
Этап 3 — Дубликаты: Реализован поиск дубликатов через MD5-хэш содержимого файлов. Функция find_duplicates проходит по списку файлов, читает каждый и считает хэш через hashlib. Результаты хранятся в словаре хэш -> список путей. В конце выводятся только те группы, где файлов два и больше.
17.06.2026
Этап 4 — Резервная копия: Реализовано сравнение оригинальной папки с бэкапом. Функция check_backup сканирует обе папки и строит два словаря с относительными путями файлов и их размерами. Затем сравнивает их и выводит три категории: файлы отсутствующие в бэкапе, изменённые файлы и лишние файлы в бэкапе. Программа принимает один или два пути — если передан один, запускается только сканирование, если два — добавляется сравнение с бэкапом.
Критерии выполнены: сравнение работает, отсутствующие, изменённые и лишние файлы видны.

29.06.2026
Исправлены ошибки: 
Первая ошибка заключалась в некорректном импорте модуля duplicates с указанием несуществующего пакета src, что было исправлено путем замены from src.duplicates import get_file_hash на from duplicates import get_file_hash. Вторая, состояла в том, что при сравнении файлов в оригинале и бэкапе использовались разные типы данных: для оригинальных файлов сохранялся их размер в байтах, а для файлов в бэкапе вычислялась хэш-сумма. Это приводило к тому, что даже идентичные по содержимому файлы определялись программой как измененные, поскольку сравнение числа и строки всегда давало ложный результат. Исправление заключалось в замене сохранения размера файла f["size"] на вычисление его хэш-суммы get_file_hash(f["path"]), что обеспечило корректное сравнение файлов по их содержимому. После внесенных изменений были проведены проверки: при тестировании разных файлов программа корректно отобразила их в списке "Изменён", а при проверке одинаковых файлов они не были включены в этот список, что подтверждает правильность внесенных исправлений.
В ходе оптимизации утилиты была полностью переработана логика управления программой: интерактивный ввод через функцию input() удален, и теперь фильтрация файлов осуществляется строго через аргументы командной строки с помощью флага --skip-ext. Это позволило полностью автоматизировать запуск скрипта в терминале и исключить остановки процесса для ожидания действий пользователя. По умолчанию утилита по-прежнему пропускает системный мусор и файлы нулевого размера, но теперь пользователь может гибко переопределять список игнорируемых расширений прямо при старте утилиты.
